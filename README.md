# Swiggy Data Analysis Dashboard – Excel

## 📌 Project Overview

This project focuses on analyzing Swiggy food-order data using Microsoft Excel. An interactive dashboard was created to understand restaurant performance, food pricing, ratings, categories, cities, and ordering trends.

## 🛠️ Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel Formulas
- Data Cleaning
- Data Analysis
- Data Visualization

## 🎯 Objectives

- Analyze food-order data
- Understand restaurant performance
- Analyze food pricing and ratings
- Compare food categories
- Identify city-wise trends
- Analyze time-based ordering patterns

## 📊 Dashboard Analysis

The dashboard includes:

- Total Orders
- Total Price
- Average Price
- Average Rating
- Restaurant Performance
- Food Category Analysis
- City-wise Analysis
- Rating Analysis
- Price Analysis
- Quarter-wise Trends
- Day-wise Trends
